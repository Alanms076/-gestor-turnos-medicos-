# 🏥 Gestor de Turnos Médicos Online

Proyecto Final — **Generación T (Stage 2)**.  
Aplicación web full-stack desarrollada bajo metodología **AI-First** y **Spec-Driven Development**, con arquitectura backend en capas (`Controller` — `Service` — `Repository`).

## 🚀 Tecnologías utilizadas
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Node.js + Express
- **Testing:** Node.js Test Runner (`node:test`)
- **Documentación & Agentes:** `docs/spec.md` y `AGENTS.md`

## ⚙️ Instalación y ejecución local

1. Clonar el repositorio:
   ```bash
   git clone https://github.com
   cd gestor-turnos-medicos
   ```
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Configurar variables de entorno:
   ```bash
   cp .env.example .env
   ```
4. Iniciar el servidor:
   ```bash
   npm start
   ```
5. Abrir en el navegador: `http://localhost:3000`

## 🧪 Ejecutar tests unitarios
```bash
npm test
```
